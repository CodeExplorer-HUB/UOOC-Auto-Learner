# 🎓 UOOC 自动化学习助手 (Auto-Learner)

基于 Python + Selenium + PyAutoGUI + Tkinter 开发的 UOOC 平台自动化辅助工具。支持自动接管浏览器、遍历章节、自动刷课、AI 自动答题（支持选择题与填空题）、防挂机弹窗处理以及拟人化鼠标轨迹模拟。

## ✨ 核心特性
- 🌓 **极客风 UI**：基于 Tkinter 打造的黑底绿字主控台，单窗口运行，告别多窗口弹窗干扰。
- 🕵️ **拟人化轨迹**：接入 `pyautogui`，利用贝塞尔曲线生成模拟真人滑动的鼠标轨迹，破解滑块/验证码检测。
- 🤖 **AI 智能答题**：接入 DeepSeek API，自动识别并完成选择题和填空题。
- 🎬 **智能刷课**：自动遍历章节目录，识别新旧版 UI 图标，自动 2 倍速静音播放。
- 🛡️ **防挂机拦截**：自动检测并处理视频播放中弹出的防挂机答题窗口，挂机不断线。
- 🔄 **断点重试**：视频卡死自动重试，页面加载超时自动刷新，抗网络波动。
